Сцены:
Scene- сцена с бэкграундом и границами
Player- сцена с игроком
Bullet- сцена с пулей

Связи:Игра начинается со сцены Scene, далее она создает Player в определенном месте. Далее по нажатию на пробел Player создает Bullet с такой же позицией.

Скрипты:
Scene- загружает сцену игрока при качале игры
Player- обрабатывает движения игрока, по нажатию на пробел загружает Bullet
Bullet- обрабатывает движения пули
