Сцены:
Scene- сцена с бэкграундом и границами
Player- сцена с игроком
Bullet- сцена с пулей
Enemy- первый тип врага, он медленный но при столкновении наносит урон
Enenmy2- второй тип врага он быстрее и умеет стрелять пулями, при столкновении ничего не происходит
Hillka- хилка, объект который при вхождении в него восстанавливает хп всем объектам у кого есть метод восстановления здоровья
Spike- шипы, объект вхождение на который наносит урон(в том числе врагам)

Связи:Игра начинается со сцены Scene, далее она создает Player в определенном месте на сцене уже расставлены spikes и Hillkes, больше они не создаются и не восстанавливаются. Далее по нажатию на пробел Player создает Bullet с такой же позициейи указывает ему на каком слое он наносит урон. Враги создаются на сцене scene с определенной периодичностью в их первоначальном месте,создается рандомно либо 1 либо 2 тип врага. Enemy2 с определенной периодичностью создает Bullet и указывает ему на каком слое он наносит урон

Скрипты:
Scene- загружает сцену игрока при начале игры, создает врагов в течении игры
Player- обрабатывает движения игрока, по нажатию на пробел загружает Bullet указывая ему на каком слое наносит урон
Bullet- обрабатывает движения пули
Enemy-медленно двигается в сторону игрока, при столкновении уничтожается и наносит урон
Enemy2- движется быстрее и периодично загружает Bullet указывая ему на каком слое наносит урон
Hillka- при вхождении вызывает у объекта метод hill если такой есть после уничтожается
Spike- при вхождении наносит урон
